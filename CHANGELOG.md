# Changelog

## 1.1.0
- [NEW FEATURE] `how_to` tells which mechanism is the right one for a given case. It ships the decisions of the core, and bundles contribute their own with a `DecisionProviderInterface` service
- [NEW FEATURE] `site_config` lists every `config_location` type of the installation with the key that sets its target and its current target
- [ENHANCEMENT] Requires `symfony/mcp-bundle` `^0.14`
